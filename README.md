# soop-multi-view

SOOP 멀티뷰 사이트입니다.

## 사용법

사이트 주소(https://soop-multi-view.netlify.app/) 뒤에 SOOP 아이디를 `/`로 구분하여 넣으면 됩니다.

아니면 좌측 상단의 메뉴 버튼을 눌러 우측 input 박스에서 추가할 수 있습니다.

## 개발 환경 설정

```bash
# 의존성 설치
pnpm install

# 개발 서버 실행
pnpm run dev
```

개발 서버가 실행되면 [http://localhost:3000](http://localhost:3000)에서 확인할 수 있습니다.

## 빌드 및 배포

```bash
# 프로덕션 빌드
pnpm run build

# 빌드 서버 실행
pnpm run serve
```
